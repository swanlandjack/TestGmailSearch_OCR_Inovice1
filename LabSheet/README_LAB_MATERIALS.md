## 💡 Teaching Tips

### For Maximum Engagement:
1. **Start with a story:** "A company processed 1000 invoices/month, spent $50k/year on data entry..."
2. **Show the 'wow' moment:** Live demo the 30-second processing
3. **Embrace failures:** When AI makes mistakes, discuss why (great learning!)
4. **Connect to business:** Ask "How would YOU use this in your company?"

### For Smooth Execution:
1. **Pair up strugglers:** Students help each other = less TA burden
2. **Have backup API keys:** For students who hit rate limits
3. **Celebrate first success:** Public recognition motivates others
4. **Time management:** Use INSTRUCTOR_GUIDE.md timeline

### For Deeper Learning:
1. **Compare models:** Have students test same invoice with different models
2. **Edge cases:** Deliberately break things to show limitations
3. **ROI calculation:** Make it real with business math
4. **Ethics discussion:** "What if AI discriminates?"
